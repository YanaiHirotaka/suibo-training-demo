# 水防訓練フィールド プロトタイプ

ブラウザで動作するTPS視点の水防訓練ゲーム用プロトタイプです。

## 現在の実装

- Three.jsによるブラウザ表示
- フィールド：210 × 195ブロック
- 1ブロック：0.3125m
- フィールド実寸：約65.625m × 60.9375m
- プレイヤー：細かいブロック構成のTPSキャラクター
- 開始時は最初のチェックポイント方向を見渡す肩越しカメラを使用し、画面比率に応じて距離・視野角・肩位置を調整しながら建物やマップ境界へのカメラ侵入を自動回避
- 開始地点：マップ右下寄り
- 開始地点左側に15 × 15 × 15ブロック程度の家を1棟配置
- 既存家から縦方向に5ブロック間隔で、色・サイズ・高さの異なる建物を2棟追加
- 家の右側から北方向へ、15ブロック幅の石畳道路を配置
- 右上ミニマップにフィールド外観と現在地を表示
- 右側に斜めの河川エリアを配置
- 地面は grass / road / river のブロック種別ごとに生成し、道路・河川は緑ブロックの上に重ねず入れ替えて配置
- 河川は水面ハイライトのみを動かす軽量な流れ表現
- 河川の上に半透明の波模様・反射テクスチャを重ね、軽量に水面の質感を表現
- 河岸に軽量な泡表現を追加し、流れに合わせて明滅
- 降雨強度に応じて道路の粗さ・反射・色調と画面露出が変化
- 避難ルート上にテクスチャ付きの濡れた路面反射をインスタンス描画で配置
- 道路へ広がる浸水面に流れる波模様を加え、降雨・水位に応じて色と透明度を変化
- 河川沿いの3D水位観測設備に、前回観測との差分、最高予測位置、警戒レベル連動の警告灯を表示
- 浸水中の移動に波紋と水しぶき、周囲の水面に雨粒の波紋を表示（スマホでは発生数を自動削減）
- ミッション・ミニマップ・訓練状況・水位計を共通HUDデザインで統一し、デスクトップでは四隅と上下へ役割別に配置
- 現在のミッションと水位を色・枠・文字サイズで優先表示
- 高齢者・子ども・近隣住民を専用配色、髪型、帽子、装備で識別可能
- NPCの待機時リアクション、声かけへの応答、左右にずれた同行隊列を追加
- 全員が避難所へ到着した際にNPCが両手を上げて喜ぶポーズを表示
- 避難成功時に避難所前へカメラを移動し、NPC集合、金色ランク、スコア加算を順番に見せる成功演出
- 河川の両岸にブロック状の柵を配置し、プレイヤーが河川へ侵入できないよう制御
- 住宅地を横断する道路、河川沿い道路、横断歩道を追加
- 歩道・欄干・橋脚を備え、実際に渡れる河川橋を追加
- 街区設計中は河川以外のベース地形を平地として生成

## マップ設定

`app.js` 冒頭の `mapConfig` に、マップの基本情報を集約しています。

- `blockSize`: 1ブロックの実寸
- `blocks.width` / `blocks.depth`: フィールドのブロック数
- `cellBlocks`: 構成図の1升あたりのブロック数
- `playerStartBlock`: プレイヤー開始位置
- `structures.startHouse`: 開始地点左側の家
- `areas.urbanRoads`: 横断道路・河川沿い道路・橋の位置と寸法
- 横断道路と既存建物が重ならないよう、アパートを北西街区へ再配置
- 幹線道路・横断道路の歩道、街路樹、街灯を自動生成
- 幹線道路と横断道路に、軽量な電柱・電線・制限速度標識・浸水注意標識を配置
- 街路樹を歩道外側、街灯を車道側へ分け、その間に連続した歩行可能空間を確保
- 編集モードの素材に「黒い道路」を追加し、ブラシ・範囲選択で黒いアスファルトを配置可能
- 編集した通路・草地・黒い道路をミニマップへ即時反映し、高さ変更後はハザード表示も更新
- 河川以外の地形全体を浸水候補にし、固定された地形の高さに応じて水没判定
- 市街地に0〜3ブロックの固定標高を設け、道路は連続した低地として維持
- 川につながる低い経路を探索し、開口部や道路から段階的に広がる浸水モデル
- 避難大通り・北側道路・避難所接続路を追加し、安全ルートを道路網へ接続
- 安全ルートの終点は、移動後の避難所位置から自動算出
- 安全ルートの再探索を目標変更・通行止め・経路逸脱時だけに限定し、歩行中の周期的な停止を抑制
- 安全ルートを水面より上に保たれる大型の発光矢印として連続表示し、光の流れで進行方向を案内
- 現在のチェックポイント・救助対象・避難所を立体的な発光マーカーで表示
- 避難所屋上に大型の案内看板と遠距離用ビーコンを設置し、接近時は自動的に発光を抑制
- プレイ領域の外周に、色・高さ・窓・屋上設備の異なる軽量な遠景街区を配置（スマホでは棟数を自動削減）
- 避難所を開始地点に近い横断道路北側へ移し、高さ13ブロック（4.0625m）の高台と徒歩用の坂道を自然に接続
- チェックポイント到達時は質問画面を挟まず次のミッションへ進み、避難所のグループ到着判定は入口手前の広い集合エリアで行う
- 経路探索は隣接地点の高低差を確認し、崖を避けて坂道を通る
- スタート地点が危険な水深になった場合、復帰先を高台の避難所前へ切り替える
- 編集モード中は訓練時間・水位上昇・災害イベント・NPC・ミッション進行を一時停止
- `terrain.flatDevelopment`: 開発用の平地生成モード

避難所と高台は `modules/shelter-terrain.js`、市街地の固定標高は `modules/terrain-elevation.js`、接続経路に基づく浸水計算は `modules/flood-spread.js` に分離しています。

ミッションの次目標、進捗、到達条件、訓練完了条件は `modules/mission-state.js` に分離しています。DOMやThree.jsに依存しない判定としてテストできるため、今後HUDや演出を変更してもミッション進行の仕様を維持できます。

今後、道路・河川・避難所・浸水エリア・避難ルートもこの設定データ側に追加していく想定です。

## 起動

```powershell
node server.mjs
```

ブラウザで `http://127.0.0.1:4175/` を開きます。

## テスト

```powershell
node --test tests/*.test.mjs
```
