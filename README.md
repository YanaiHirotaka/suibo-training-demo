# 水防訓練フィールド プロトタイプ

ブラウザで動作するTPS視点の水防訓練ゲーム用プロトタイプです。

## 現在の実装

- Three.jsによるブラウザ表示
- フィールド：105 × 120ブロック
- 1ブロック：0.3125m
- フィールド実寸：約32.8125m × 37.5m
- プレイヤー：細かいブロック構成のTPSキャラクター
- 開始地点：マップ右下寄り
- 開始地点左側に15 × 15 × 15ブロック程度の家を1棟配置
- 既存家から縦方向に5ブロック間隔で、色・サイズ・高さの異なる建物を2棟追加
- 家の右側から北方向へ、15ブロック幅の石畳道路を配置
- 右上ミニマップにフィールド外観と現在地を表示
- 右側に斜めの河川エリアを配置
- 地面は grass / road / river のブロック種別ごとに生成し、道路・河川は緑ブロックの上に重ねず入れ替えて配置
- 河川は水面ハイライトのみを動かす軽量な流れ表現
- 河川の上に半透明の波模様・反射テクスチャを重ね、軽量に水面の質感を表現
- 河川の両岸にブロック状の柵を配置し、プレイヤーが河川へ侵入できないよう制御
- 住宅地を横断する道路、河川沿い道路、横断歩道を追加
- 歩道・欄干・橋脚を備え、実際に渡れる河川橋を追加
- 街区設計中は河川以外のベース地形を平地として生成

## マップ設定

`app.js` 冒頭の `mapConfig` に、マップの基本情報を集約しています。

- `blockSize`: 1ブロックの実寸
- `blocks.width` / `blocks.depth`: フィールドのブロック数
- `cellBlocks`: 構成図の1升あたりのブロック数
- `playerStartBlock`: プレイヤー開始位置
- `structures.startHouse`: 開始地点左側の家
- `areas.urbanRoads`: 横断道路・河川沿い道路・橋の位置と寸法
- 横断道路と既存建物が重ならないよう、アパートを北西街区へ再配置
- 幹線道路・横断道路の歩道、街路樹、街灯を自動生成
- 避難大通り・北側道路・避難所接続路を追加し、安全ルートを道路網へ接続
- 安全ルートの終点は、移動後の避難所位置から自動算出
- `terrain.flatDevelopment`: 開発用の平地生成モード

今後、道路・河川・避難所・浸水エリア・避難ルートもこの設定データ側に追加していく想定です。

## 起動

```powershell
node server.mjs
```

ブラウザで `http://127.0.0.1:4175/` を開きます。
